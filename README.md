# Kisan2Consumer 🌱

**Direct Farmer-to-Consumer Agricultural Marketplace**
Built for Smart India Hackathon 2026 — Problem Statement SIH26033

## About
Kisan2Consumer connects farmers directly with consumers, reducing dependency
on unnecessary intermediaries in the agricultural supply chain.

## Tech Stack (Frontend)
- React.js + Vite
- Tailwind CSS
- React Router
- Lucide Icons

## Pages
- Landing Page
- Login/Signup (Farmer & Consumer)
- Farmer Dashboard (Add/Manage Products)
- Consumer Marketplace (Browse, Search, Cart)
- Checkout

## Run Locally
\`\`\`
npm install
npm run dev
\`\`\`
